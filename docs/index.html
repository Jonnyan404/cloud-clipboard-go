Cloud Clipboard
特性 快速开始 API 文档 GitHub

手机复制，电脑粘贴

自托管的跨设备剪贴板与文件中转。数据留在你自己的服务器上， iOS 快捷指令、Android、浏览器、路由器都能用。

去 GitHub 看看 怎么部署 REST API

它有什么

真·自托管

Go 单二进制，内嵌前端，跑起来就一个进程；也可以丢到 Cloudflare Workers 上白嫖。

多端接入

网页、iOS 快捷指令（分享菜单直接发）、Android、OpenWrt，还有实时推送。

房间与密码

按房间隔离，可设全局密码或每个房间单独的密码；还有短期分享链接。

文件也能传

文本、图片、文件都能发，带过期时间；大文件走分块上传。

界面能换皮肤

六种界面模式（时间流 / 聊天气泡 / 便签 / 终端…），内置中华传统色。

Markdown 预览

发过来的 .md 文件可以直接渲染看排版，也能一键切回原文。

快速开始

Docker（推荐）

docker run -d --name cloud-clipboard \
  -p 9501:9501 \
  -v /your/data:/app/server-node/data \
  ghcr.io/jonnyan404/cloud-clipboard-go:latest

或者单二进制

从 Releases 下载对应平台的包，解压后直接跑，前端已经嵌在里面了。

配上快捷指令

打开部署好的网页，点输入框旁边的 ⚡ 图标，里面有 iOS 和 Android 的导入包 （含下载、链接和二维码），导入后填上服务器地址即可。

自己写客户端

接口是普通的 REST + WebSocket，两个后端共用一份契约： REST API 文档。
